# 정류장 3D 배경 구성 기획

**작성:** 개발(세션) · 2026-08-25 · **상태: 초안 — 확인 요청**
**배경:** `/story-vr`의 3D 그레이박스가 "전체 구조도 이상하고 나무 배치도 이상하다"는 피드백을 받았다. 코드로 바로 고치기 전에, 예시 이미지를 포함한 기획서로 먼저 합을 맞춘다.

## 1. 기준 문서

이 기획은 아래 두 자료를 그대로 따른다 — 새로 지어내지 않는다.

1. **`Bus/규격/정류장_스크립트_v2.md` §1** — 사건별 방위·거리 서술 (원문 그대로)
2. **`Bus/ArtWork_Final/`** — 실제 원화 (전체뷰·메인뷰·사이드뷰 × 4장르)

## 2. 360도 배치도

방위각은 **정면(도로 방향) = 0°, 시계방향 = 오른쪽(+)** 기준이다.

![360도 배치도](360도_배치도.svg)

| 방위각 | 요소 | 거리감 | 근거 |
|---|---|---|---|
| 0° | 도로 정면 (왕복 4차선, 왼쪽에서 나타나 오른쪽 숲 뒤로 굽어 사라짐) | 근~원거리 | v2.md §1 |
| -38° | 카페 (창 조명, 사람이 나옴) | 원거리(~50m 축소) | §1-2 |
| +30°~+90° | 침엽수림 + 호수공원 진입로 (고양이 등장 지점) | 도로 건너편 | §1, §1-5 |
| +72° | 정류장 오른쪽 유리 — 찢어진 포스터 | 근거리(유리 위) | §1-1 |
| +135° | 개구리 (소리만, 시각 자산 불필요) | 근거리 풀숲 | §1-4 |
| 180° | 비 젖은 풀숲 (벤치 바로 뒤) — **담장 아님** | 근거리 | §1 |
| -115° | 두 번째 고양이 울음 (소리만) | 화면 밖 | §1-5 |
| 나머지 전 방위 | 배경 숲 링 (ForestRing) | 원거리(반경 13~16) | 빈 하늘 방지용, 스크립트에 없는 채움 |

## 3. 원화 대조 — 무엇을 맞춰야 하는가

아래 세 장이 기준이다 (파일: `Bus/ArtWork_Final/1_디폴트/`).

**01_전체뷰** — 정류장을 밖에서 본 3/4 와이드 샷. 지붕·기둥·벤치의 비례, 도로 폭, 좌측 담장+나무 라인의 기준.
![전체뷰](../ArtWork_Final/1_디폴트/01_전체뷰_디폴트_보정.png)

**02_메인뷰** — 벤치에서 정면(0°)을 본 시점. 도로 건너 억새 앞줄 → 침엽수림 → 하늘. **나무가 지붕보다 3~4배 높고 극단적으로 가늘다** — 이게 지금 "나무 배치가 이상하다"고 느껴지는 핵심일 가능성이 크다: 지금 구현은 나무가 너무 촘촘하고 굵게 들어가 있다.
![메인뷰](../ArtWork_Final/1_디폴트/02_메인뷰_디폴트_보정.png)

**03_사이드뷰** — 벤치에서 살짝 오른쪽(카페 쪽 도로가 보이는 방향)을 본 시점. 도로가 화면 오른쪽으로 굽어 사라지는 각도, 왼쪽엔 담장+나무.
![사이드뷰](../ArtWork_Final/1_디폴트/03_사이드뷰_디폴트_보정.png)

**지금 구현과 원화의 차이 (추정 — 확인 필요)**

| 항목 | 원화 | 지금 구현 (추정 문제) |
|---|---|---|
| 나무 밀도 | 듬성듬성, 개별 나무가 구분됨 | 너무 촘촘하게 겹쳐 "숲 벽"처럼 보임 |
| 나무 배치 규칙 | 도로 건너편에만 뚜렷한 열, 나머지는 훨씬 옅고 먼 배경 | 배경 링이 전 방향에 균일한 밀도로 깔려 인위적으로 보임 |
| 도로-숲 경계 | 억새 앞줄 → 숲, 경계가 자연스러움 | 도로 폭·나무 시작 위치가 여러 번 수정되며 어긋났을 가능성 |
| 카페 크기·위치 | 아주 작고 멀게, 실루엣 수준 | 상자+원뿔 지붕이 너무 커서 가깝게 보일 수 있음 |

## 4. 확인 요청

아래 질문에 답을 주시면 이 기획서를 확정하고 그 다음에 코드를 고칩니다.

1. "전체 구조가 이상하다"는 게 **비율(카페가 너무 큼/가까움, 도로가 너무 넓음 등)** 문제인지, **배치(요소가 있어야 할 자리가 아님)** 문제인지, **양쪽 다**인지?
2. 나무는 **더 듬성듬성하게** 줄이고, 색·형태보다 **개별 나무가 뚜렷하게 구분되는 것**을 우선할까요?
3. 배경 숲 링(전 방위 채움)을 유지하되 **밀도를 낮추고 훨씬 멀리(더 흐리게)** 두는 방향이 맞을까요, 아니면 다른 방식(예: 그림 텍스처를 먼 배경에 씌우기)을 원하시나요?
