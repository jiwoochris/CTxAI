# 💡 조명 프리셋 저장 / 불러오기

**받는 분:** 아트
**작성:** 개발 · 2026-08-07
**쓰는 날:** 8/9 시험 제작 (중립 1 + 순수 1) · 8/14 5세트
**근거:** 요청서 v5.0 D1 · D2 · §2.4

---

## 0. 무엇을 하시면 되나

**팀 화면의 `/whitebox` 에서 조명·안개·환경광을 눈으로 조절하고 「저장」을 누르시면 됩니다.**

PlayCanvas 에디터는 더 이상 쓰지 않습니다 — 아트가 다른 3D 툴로 작업하게 되면서, 조명도 그 툴이 아니라
이 웹 화면에서 직접 조절합니다. 숫자 표를 쓰실 필요 없고, 파일을 보내실 필요도 없습니다.
**「저장」을 누르면 개발에게 바로 갑니다.**

---

## 1. 화이트박스 열기

**팀 화면의 `/whitebox` 로 가시면 됩니다.** 로그인 없음, 설치할 것도 없습니다.

화면 오른쪽에 패널이 있습니다.

```
┌─────────────────────────┐
│ 조명 프리셋              │
│ ┌─────────────────────┐ │
│ │ lp_H — 🖤 공포    ▾ │ │
│ └─────────────────────┘ │
│  📂 불러오기 · 💾 저장   │
│                         │
│ 환경광 · 노출 · 안개     │
│ Key(조명) · Fill(조명)  │
└─────────────────────────┘
```

패널 아래 3D 화면에서 지금 조명이 정류장 화이트박스(구조물·벤치·표지판)에 어떻게 비치는지
바로 보면서 조절할 수 있습니다.

---

## 2. 저장

1. 패널에서 만들고 있는 프리셋을 **고릅니다** (`lp_neutral` / `lp_H` / `lp_R` / `lp_C` / `lp_F`)
2. 환경광·노출·안개·조명별 색·세기를 **원하는 대로 조절**합니다 — 3D 화면에 바로 반영됩니다
3. **💾 저장**을 누릅니다 → **개발에게 바로 갑니다**

📐 파일을 보내실 필요가 없습니다. 팀 화면의 「조명 프리셋」 칸에 바로 뜹니다.

**저장되는 것**

| | 무엇 |
|---|---|
| 씬 | 환경광 · 안개(종류·색·농도) · 노출 |
| 조명 | 조명마다(`Key`·`Fill`) 색 · 세기 · 켜짐 여부 |

🔧 **조명 이름(`Key`, `Fill`)은 다섯 장 모두 같습니다** — 화이트박스가 코드로 만든 고정된 조명이라
아트가 이름을 따로 맞출 필요가 없습니다. 코드가 이 이름으로 짝을 맞춰 섞습니다.

📐 **어떤 프리셋에서 조명을 꺼 두는 것도 괜찮습니다.** 반대쪽에서 그 조명의 세기를 0으로 취급해
자연스럽게 꺼집니다.

---

## 3. 불러오기

**📂 불러오기** → 서버에 저장된 것을 고르면 그때 상태로 화면이 되돌아갑니다.

이럴 때 씁니다.

- 어제 만든 공포를 다시 열어 조금 고치고 싶을 때
- 중립을 불러와서 그걸 출발점으로 로맨스를 만들 때 ← **이 방식을 권합니다**
- 이것저것 만지다 망가졌을 때 되돌리기

⚠️ **불러오기는 지금 화면을 덮어씁니다.** 저장 안 한 작업이 있으면 먼저 저장하세요.

---

## 4. 만드실 것 — 다섯 장

| 이름 | 무엇 | 언제 |
|---|---|---|
| `lp_neutral` | **중립** — 체험 시작 ~ 1:40. 관객이 가장 먼저, 가장 오래 보는 화면 | 8/9 시험 · 8/14 |
| `lp_H` | 🖤 공포 | 8/14 |
| `lp_R` | 💗 로맨스 | 8/14 |
| `lp_C` | 💛 코미디 | 8/14 |
| `lp_F` | 💜 판타지 | 8/14 |

🔧 **조합 프리셋(`lp_R-H` 같은 것)은 만들지 마세요.** 열여섯 배합은 코드가 이 다섯 장 중 두 장을 섞어 전부 만듭니다. 「경계하는 그리움(R-H)」은 로맨스 프리셋과 공포 프리셋의 혼합입니다.

📐 **중립의 요구는 하나뿐입니다 — 네 장르 어느 쪽으로 넘어가도 자연스러운 출발점.** 이미 공포 쪽으로 기울어 있으면 로맨스로 가는 전환이 어색해집니다.

📐 **8월 합격 기준은 「넷이 서로 구분되는가」 하나입니다.** 거칠어도 됩니다. 8/22는 시연이지 완성이 아니고, 완성도는 9월입니다.

---

## 5. 8/9에 하실 일 — 형식 검증

**두 장만 만들어 주세요 — 중립 1 + 순수 아무거나 1종.**

이건 예쁘게 만드는 작업이 아니라 **형식이 맞는지 보는 작업**입니다. 대충 만드셔도 됩니다.

```
8/9(일)  아트   중립 1 + 순수 1 저장 → 개발에 전달
8/10(월) 개발   런타임에 넣어 보고 형식 피드백
8/14(금) 아트   여기서 형식이 맞으면 나머지 4세트를 안심하고 진행
```

🔴 **8/10에 형식 문제가 나오면 그날 고칩니다.** 8/14에 다섯 장을 다 만든 뒤에 형식이 틀린 걸 알면 다시 만들어야 하므로, 8/9 두 장을 먼저 하는 것입니다.

## 6. 개발이 이 파일로 하는 일

| 파일 | 무엇 |
|---|---|
| `app/whitebox/page.jsx` (앱) | 조명 조절 화면. 여기서 저장한 값이 `/api/preset`으로 갑니다 |
| [`lightingPresets.js`](lightingPresets.js) | 프리셋 적용 · 두 장 섞기 · 전환 애니메이션 |
| [`test-lerp.mjs`](test-lerp.mjs) | 섞기 검사 20개 (`node test-lerp.mjs`) |
| [`preset.schema.json`](preset.schema.json) | 저장 파일 형식 |

```js
// 로맨스 사건 + 공포 태도 = "경계하는 그리움"
applyPreset(app, lerpPreset(presets.lp_R, presets.lp_H, 0.35));

// 1:40 — 중립에서 사건 장르로 4초 동안
transitionTo(app, presets.lp_neutral, presets.lp_H, 4);
```

---

**질문 없으셔도 됩니다.** 패널이 안 뜨거나 「조명 0개」가 나올 때만 말씀 주세요.
