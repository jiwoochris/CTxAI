## 3. 로컬 개발 · 배포

### 로컬 실행

```bash
cd /Users/drew/CTxAI/ctxai-busstop-xr-audio-proto
npm run dev
```

`.env.local`에 필요한 값(이미 채워져 있음, gitignore됨):
`OPENROUTER_API_KEY` · `ELEVENLABS_API_KEY` · `SUPABASE_URL` · `SUPABASE_SERVICE_ROLE_KEY` · `V3_EMOTION_TAGS=1`

⚠️ 이 파일에 키가 중복 정의돼 뒤엣것이 이겨서 인증이 깨진 적이 있었습니다(`Invalid Compact JWS` 에러로 나타남). 이상한 인증 에러가 나면 **`.env.local`에 같은 키가 두 번 이상 들어있지 않은지 먼저 확인**하세요.

### 배포

```bash
cd /Users/drew/CTxAI/ctxai-busstop-xr-audio-proto
TOK=$(cat .vercel-token | tr -d '[:space:]')
npx --yes vercel deploy --prod --token="$TOK" --yes
```

`.vercel-token`은 gitignore된 로컬 파일입니다 (Vercel Personal Access Token). **이미 있으면 지우지 말고 재사용하세요** — 토큰 발급을 매번 새로 받을 필요 없습니다. 없거나 무효하면:

```bash
curl -s -H "Authorization: Bearer $TOK" https://api.vercel.com/v2/user
```
로 유효성 먼저 확인 (`user` 필드가 있으면 유효).

환경변수를 새로 추가/변경해야 하면:
```bash
printf '값' | npx --yes vercel env add 변수이름 production --token="$TOK" --yes
printf '값' | npx --yes vercel env add 변수이름 preview --token="$TOK" --yes
```

## 4. 지금까지 배운 것 (같은 실수 반복 방지)

- **Supabase Storage 새 형식 키(`sb_secret_...`)는 `Authorization` 헤더만으론 인증 안 됨** — `apikey` 헤더를 같이 보내야 함 (`lib/store.js`의 `authHeaders()` 참고)
- **Supabase Storage는 객체 키에 비-ASCII(한글 등)가 있으면 URL 인코딩과 무관하게 거부함** — 그래서 저장 키는 `slotId+확장자`로 고정하고, 사람이 올린 원래 파일명은 `records.json`에만 보관함
- **파일 확장자를 MIME 타입만으로 판정하면 안 됨** — curl 등 많은 클라이언트가 `.m4a`에도 `application/octet-stream`을 보냄. 원본 파일명의 확장자를 먼저 보고, 없을 때만 MIME 매핑으로 넘어가야 함 (`app/api/mood/route.js`의 `extensionFor()` 참고)
- **`window.prompt()`/`alert()`를 자동화 대상 페이지(PlayCanvas 에디터 등)에서 쓰면 안 됨** — 네이티브 다이얼로그가 뜨면 그 탭의 JS 실행이 멈추고, 사람이 직접 눌러야만 풀림. 화면 안에 뜨는 커스텀 UI로 대체할 것
- **무거운 라이브러리(3D 뷰어 등)는 동적 import로** — 실제로 쓸 때만 불러오면 초기 번들에 영향 없음
- **브라우저가 클릭 한 번으로 북마크를 만들게 하는 건 불가능** — 모든 브라우저가 스팸 방지로 막아둠. 드래그가 유일한 방법
