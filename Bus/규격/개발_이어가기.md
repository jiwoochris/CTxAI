## 6. 지금까지 배운 것 (같은 실수 반복 방지)

### 기존 (v1.1 시절부터)
- Supabase Storage 새 형식 키(`sb_secret_...`)는 `apikey` 헤더도 같이 보내야 인증됨
- Supabase Storage 객체 키에 비-ASCII 금지 — `slotId+확장자`로 고정, 원본 파일명은 `records.json`에만
- `@react-three/fiber@8.18.0` + `@react-three/drei@9.122.0` + `three@0.183.0` 고정 (React 18/Next 14, `@google/model-viewer` peer 호환)
- 조명 프리셋·할일·대사오디오·SFX는 파일이 아니라 Supabase에 저장됨 — 테스트로 올리면 팀 전체가 보는 실데이터가 됨

### 이번 세션에서 새로 배운 것
- **ElevenLabs 무료 플랜은 API로 라이브러리/공유 보이스를 절대 못 씀** — `free_users_allowed: true`로 표시된 보이스도 계정에 "추가"는 되지만 API로 "생성"은 402 `payment_required`로 막힘. **웹사이트 UI(Claude-in-Chrome으로 직접 클릭)로 생성하면 이 제한이 안 걸림.** 계정 자체 기본 프리메이드 보이스(Adam, Rachel 등 영어 목록)만 API로 바로 됨.
- **ElevenLabs 웹사이트에서 한국어 텍스트 입력할 때 `\uXXXX` 이스케이프를 손으로 계산해서 넣으면 안 됨** — 여러 번 오타 발생(웃지→우지, 찢어진→짢어진 등). 코드포인트가 필요하면 `python3 -c "print(hex(ord(...)))"` 로 검증하고, 되도록 리터럴 한글을 그대로 타이핑할 것.
- **Pixabay "Free download" 버튼은 첫 클릭에 안 눌릴 때가 많음** — 로케일 전환(영어→한국어) 리다이렉트가 첫 클릭에 소비되는 경우가 있어 2~3번 클릭 필요. 클릭 후 다운로드 확인은 파일 존재 여부로, 안 되면 스크린샷으로 "Nice one!" 확인 모달이 떴는지 볼 것. **브라우저 창 너비가 세션 중 슬쩍 바뀔 수 있어(1552↔1568px) 고정 좌표 클릭이 가끔 빗나감** — 안 되면 스크린샷으로 버튼 위치 재확인.
- **Vercel 서버리스 함수는 요청 바디가 ~4.5MB 넘으면 413(FUNCTION_PAYLOAD_TOO_LARGE)로 거부함** — 정규화된 스테레오 WAV(5.3MB)를 못 올려서 모노로 다운믹스(2.5MB)해서 우회함. 큰 오디오/모델 파일을 `/api/assets`류 엔드포인트로 올릴 때 이 제한을 염두에 둘 것.
- **`/api/assets` 슬롯에 새 변형(variant)을 올려도 자동으로 "선택"되지 않음** — 슬롯당 **맨 처음 업로드만** 자동 선택되고, 그 다음부터는 `/api/assets/choose`를 명시적으로 호출해야 함. 이걸 몰라서 BGM 4트랙이 팀이 버전 2~6까지 올렸는데도 계속 버전 1(v1)만 서비스되고 있었음 — **새 버전을 올렸는데 안 바뀐 것 같으면 이 선택 여부부터 확인할 것.**
- **ElevenLabs 공유 라이브러리 보이스는 원작자가 언제든 내릴 수 있음** — "Sunhee"(블랙코미디 할머니 보이스)가 소유자에 의해 내려갔다는 알림을 받음(730일 유예). 이미 생성된 오디오는 안전하지만, 나중에 재생성이 필요하면 그 보이스를 못 쓸 수 있음.
- **LUFS 정규화는 이 환경에서 진짜 ITU-R BS.1770이 아니라 RMS 근사치임** (ffmpeg/scipy 없어서). 내부 프로토타입 목적으로는 충분하지만 프로덕션 마스터링엔 부족 — 필요하면 실제 오디오 도구로 재작업.
- 신뢰 안 되는 사이트에서 바이너리(ffmpeg 스태틱 빌드 등)를 받아서 실행하는 대신, 있는 도구(macOS `afconvert`, 순수 Python `wave`/`struct`)로 우회하는 걸 우선함 — 이 판단 기준을 유지할 것.

5. 행동 기반 판정: `/whitebox`에 머리 포즈 로깅 패널 먼저 붙이고 실제 사람 파일럿 테스트
6. `lib/measure/dialogue.js`를 `대사양식_v2.csv` 스키마에 맞게 재작성
