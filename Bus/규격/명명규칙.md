# 3. GLB 규약

안 맞으면 런타임에서 안 뜨거나 좌표가 어긋납니다. **일곱 개뿐입니다.**

| 항목 | 규약 |
|---|---|
| 파일 형식 | **GLB** (glTF 2.0 binary) — `.gltf` + 별도 텍스처 아님 |
| 축 · 단위 | **Y-up, 미터. 1 unit = 1m** |
| 씬 원점 | **벤치 착석 지점 바닥 = (0, 0, 0)** |
| 관객 눈높이 | **앉은 자세 Y = 1.15m** 기준으로 디테일 배분 — 서 있는 시점 아님 |
| 피벗 | 각 오브젝트 피벗은 **바닥 접지면 중앙** |
| 텍스처 | PNG / JPG, 한 장 최대 **2048 × 2048** |
| 애니메이션 | **루트 모션 없음** — 위치는 코드가 제어 |

📐 **폴리곤 상한은 아직 없습니다.** 8/17 T4에서 Quest 3로 실측한 뒤에 알려 드립니다. 그 전까지는 신경 쓰지 마시고 만들고 싶은 대로 만드세요. 부록에 적힌 「삼각형 30만」은 근거 없는 임시 숫자입니다.

## 3.1 텍스처 — 요청 하나

**조명이 색을 입힐 수 있는 상태로 주세요.** 이것 하나뿐입니다.

같은 정류장이 네 장르로 읽혀야 하는데, 텍스처에 색이 이미 박혀 있으면 조명을 바꿔도 그 색이 비쳐 나옵니다. 그러면 장르가 갈리지 않습니다.

필요한 건 숫자가 아니라 **"조명을 바꿨을 때 실제로 색이 바뀌는가"** 입니다 (8/12 T1). 부록의 「채도 15% 이하」도 근거 없는 임시값이라, T1 결과를 보고 아트가 정하시면 됩니다.

## 3.2 표지판 — 구조 요구 2개

관객이 말한 단어를 **정류장 이름 자리에 실시간으로 써 넣습니다.**

1. 이름이 들어갈 자리를 **평면 사각형 하나로 분리** — 별도 머티리얼로
2. 그 면의 **UV를 0~1 전체로** 펴 주세요. 코드가 면 전체에 글자 이미지를 그립니다

머티리얼 이름은 `mat_nameplate`를 기본으로 잡아 두었습니다. 다른 이름을 쓰시면 `manifest.json`의 `models.sign.nameplateMaterial`만 고치면 됩니다.

나머지 노선도 디자인(노선, 낡음, 벗겨진 코팅)은 전부 자유입니다.

🔧 글자 값(색 `#F5F2E8` / Pretendard Bold / 면 높이의 45%)은 개발이 정했습니다. **아트가 확인하실 것은 하나입니다 — 이름 자리 판이 충분히 어둡고 균일한가.** 글자는 1분 50초부터 끝까지 계속 보이므로 중립 조명에서도 읽혀야 합니다 (8/12 T2).

## 3.3 NPC 리그 — 조건 3개

1. **머리 본을 이름으로 노출**해 주세요 (`Head`, 또는 알려 주시는 이름). 시선 방향을 코드가 섞습니다
2. **루트 모션 없이** 제자리 애니메이션으로. 벤치와의 거리는 코드가 움직입니다
3. 클립은 **루프**로. 길이는 자유

**얼굴 표정은 만들지 않습니다.** 어두운 정류장에서 표정은 보이지 않습니다.

# 4. manifest.json — 이게 뭐고 왜 있나

`manifest.json`은 **코드가 부르는 이름 → 실제 파일 이름** 을 적어 둔 표 한 장입니다.

```
코드:              "장르 소품 R을 띄워"
manifest.json:     models.genreProps.R.file = "prop_romance.glb"
디스크:            assets/prop_romance.glb
```

**이 층이 있어서 좋은 점:**

- 파일 이름을 바꾸고 싶으면 `file` 값만 고치면 됩니다. 코드는 손대지 않습니다
- 아직 없는 에셋을 `"status": "missing"` 으로 두면 **런타임이 회색 상자 / 무음으로 대신 띄우고 그냥 진행합니다.** 에셋을 기다리지 않고 로직을 검증할 수 있습니다
- 파일이 도착하면 `"status": "final"` 로 바꾸는 것만으로 갈아 끼워집니다

## 4.1 status 값 세 개

| 값 | 뜻 | 런타임 동작 |
|---|---|---|
| `missing` | 아직 없음 | 회색 상자 / 무음으로 대체하고 콘솔에 경고 |
| `draft` | 초안 | 정상 로드. 콘솔에 「초안」 표시 |
| `final` | 확정 | 정상 로드 |

**8/22 시연 합격 기준은 `missing`이 0개인 것이 아닙니다.** 8월에 필요한 것만 `draft` 이상이면 됩니다.

## 4.2 채워 주실 칸

대부분은 개발이 채워 두었습니다. **역할별로 손댈 곳은 아래뿐입니다.**

| 역할 | 어디 | 무엇 |
|---|---|---|
| 아트 | `models.*.file` | 이름을 다르게 두셨다면 그것만 |
| 아트 | `models.sign.nameplateMaterial` | 머티리얼 이름을 다르게 두셨다면 |
| 아트 | `models.npc.headBone` | 머리 본 이름이 `Head`가 아니라면 |
| 사운드 | `audio.voice.voiceId` | **8/8 — Voice Design ID. 이거 하나가 9월까지 전부 걸려 있습니다** |
| 사운드 | `audio.bgm.*.lufsIntegrated` | 실측 integrated LUFS (권장 −20, 네 트랙 동일) |
| 사운드 | `audio.bgm.*.truePeakDb` | 8/8 T3 실측 트루 피크. **목표 −9를 못 맞춰도 그대로 주고 숫자만 적어 주세요** |

📐 나머지 칸(조명 전환 시각, 글자 값, NPC 제어 범위)은 개발이 관리합니다. 고치실 필요 없습니다.

## 4.3 검증

파일을 채운 뒤 이걸 돌리면 규칙 위반을 잡아 줍니다.

```bash
node Bus/규격/validate-manifest.mjs Bus/규격/manifest.json
```

# 5. 부탁 하나

**이름이 마음에 안 드시면 바꾸셔도 됩니다.** 다만 바꾸신 뒤에 `manifest.json`을 같이 고쳐 주시거나, 아니면 그냥 "이렇게 바꿨어요" 한 줄만 주세요. 개발이 반영합니다.

**가장 곤란한 경우는 이름이 조용히 달라지는 것**입니다. 런타임에서 에셋이 안 뜨는데 원인 찾는 데 시간이 갑니다.
