## 1. 원안을 기준에 대고 검사해 봤습니다

합격 조건은 하나입니다 — **네 갈래(공포·로맨스·코미디·판타지)로 전부 답할 수 있는가.**

각 원안에 대해 태도별로 실제 답변을 써 보았습니다.

| 사건 | 원안 | 공포 | 로맨스 | 코미디 | 판타지 | 판정 |
|---|---|:-:|:-:|:-:|:-:|:-:|
| 🖤 공포 | "방금 그거… 그쪽도 보셨어요?" | ✅ | **❌** | ✅ | ✅ | 3/4 |
| 💗 로맨스 | "그 사람이 지금 저 버스에서 내리면, 어떨 것 같아요?" | ✅ | ✅ | ✅ | ✅ | **4/4** |
| 💛 코미디 | "…이거, 원래 이런 데예요?" | ✅ | △ | ✅ | **❌** | 2.5/4 |
| 💜 판타지 | "지금 저기, 뭐가 지나갔죠?" | ✅ | **❌** | ✅ | ✅ | 3/4 |

**네 개 중 하나만 통과했습니다.** 그리고 막히는 자리가 한쪽으로 쏠려 있습니다 — **로맨스 태도가 세 문장에서 다 막힙니다.**

### 왜 로맨스만 막히는가

통과한 문장 하나와 막힌 문장 셋을 나란히 놓으면 차이가 보입니다.

```
✅  "그 사람이 지금 저 버스에서 내리면, 어떨 것 같아요?"    ← 사람 · 마음을 물음
❌  "방금 그거… 그쪽도 보셨어요?"                          ← 현상 · 정체를 물음
❌  "…이거, 원래 이런 데예요?"                             ← 장소 · 정체를 물음
❌  "지금 저기, 뭐가 지나갔죠?"                            ← 현상 · 정체를 물음
```

**두 가지가 동시에 다릅니다.**

| | 통과한 문장 | 막힌 문장 |
|---|---|---|
| 무엇을 가리키나 | **사람** ("그 사람") | 현상 · 장소 ("그거", "저기", "이런 데") |
| 무엇을 묻나 | **당신의 마음** ("어떨 것 같아요") | 대상의 정체 ("보셨어요", "뭐가", "원래") |

정체를 묻는 질문에는 **따뜻함이 들어갈 자리가 없습니다.** "저게 뭐였죠?"에 로맨스로 답하려면 질문을 무시해야 합니다. 반면 공포·코미디·판타지는 정체를 묻는 질문에도 잘 붙습니다 — 무섭다 / 별거 아니다 / 이상하다 는 전부 정체에 대한 반응이거든요.

**그래서 원안대로 가면 로맨스 태도가 거의 안 뽑힙니다.** 열여섯 배합 중 로맨스 태도가 들어간 네 개(H-R · R-R · C-R · F-R)가 비게 됩니다. 요청서에 적힌 위험이 정확히 이 모양으로 나타납니다.

📐 **이건 판정 임계값으로 못 풉니다.** 관객이 로맨스로 답할 수 없는 질문을 받았는데 코드가 로맨스 점수를 올릴 방법은 없습니다.

## 2. 초안 4종

### 🖤 공포 사건

| | 문구 |
|---|---|
| **A안** (원안) | "방금 그거… 그쪽도 보셨어요?" |
| **B안** (제안) | **"혹시 누구랑 같이 오셨어요?"** |

**B안이 여는 네 갈래**

| 태도 | 이렇게 답할 수 있습니다 |
|---|---|
| 🖤 공포 | "…아뇨. 혼자예요." |
| 💗 로맨스 | "네, 곧 올 거예요." |
| 💛 코미디 | "혼자죠. 이 고생을 왜 나눠요." |
| 💜 판타지 | "같이 왔는데… 어디 갔는지 모르겠네요." |

🔧 **사람을 가리키는 질문으로 바꾼 것**뿐입니다. 공포 사건의 불안은 그대로 두고, 그 불안을 *혼자인가 / 함께인가* 로 받게 했습니다.

---

### 💗 로맨스 사건

| | 문구 |
|---|---|
| **A안** (원안) | **"그 사람이 지금 저 버스에서 내리면, 어떨 것 같아요?"** ← 그대로 쓰시길 권합니다 |
| B안 | (없음) |

**네 갈래가 이미 열려 있습니다.** 손댈 이유가 없습니다.

| 태도 | 답 |
|---|---|
| 🖤 공포 | "무서울 것 같은데요." |
| 💗 로맨스 | "반갑겠죠." |
| 💛 코미디 | "웃기겠네요. 이 시간에." |
| 💜 판타지 | "실감이 안 날 것 같아요." |

📐 **이 문장이 나머지 셋의 본보기입니다.** 사람을 가리키고, 마음을 묻습니다.

---

### 💛 코미디 사건

| | 문구 |
|---|---|
| **A안** (원안) | "…이거, 원래 이런 데예요?" |
| **B안** (제안) | **"여기 사람들, 다들 어디 가는 걸까요?"** |

**B안이 여는 네 갈래**

| 태도 | 이렇게 답할 수 있습니다 |
|---|---|
| 🖤 공포 | "모르는 게 나을 것 같은데요." |
| 💗 로맨스 | "다들 집에 가겠죠. 누가 기다리고 있고." |
| 💛 코미디 | "저 사람은 야근이죠. 표정 보세요." |
| 💜 판타지 | "안 가는 것 같은데요. 계속 여기 있는." |

🔧 원안의 **"이런 데"** 는 장소의 정체를 묻는 말이라 로맨스도 판타지도 붙기 어려웠습니다. 대상을 사람으로 옮기고 정체 대신 **행선지**를 묻게 했습니다.

---

### 💜 판타지 사건

| | 문구 |
|---|---|
| **A안** (원안) | "지금 저기, 뭐가 지나갔죠?" |
| **B안** (제안) | **"그쪽 눈에도 저 사람 보여요?"** |

**B안이 여는 네 갈래**

| 태도 | 이렇게 답할 수 있습니다 |
|---|---|
| 🖤 공포 | "…아무도 없는데요." |
| 💗 로맨스 | "네, 저기 서 계시네요." |
| 💛 코미디 | "당연히 보이죠. 왜요?" |
| 💜 판타지 | "보이는데… 좀 이상하게 보여요." |

🔧 판타지 사건에서 가장 잘 맞는 형태입니다. **같은 것을 보고 있는가**를 묻는 질문이라, 이 작품의 주제("너 나랑 다른 걸 봤네")와도 겹칩니다.

⚠️ 다만 공포 태도의 답("아무도 없는데요")이 **너무 강합니다.** 관객이 이렇게 답하면 판타지 사건인데 공포로 확 기울 수 있습니다. 이게 문제라고 보시면 A안을 쓰시는 게 안전합니다.

## 3. 정리 — 이대로 가면 이렇게 됩니다

| | 공포 | 로맨스 | 코미디 | 판타지 |
|---|:-:|:-:|:-:|:-:|
| **A안 전부 채택** | 3/4 | 4/4 | 2.5/4 | 3/4 |
| **B안 채택 (로맨스는 원안)** | 4/4 | 4/4 | 4/4 | 4/4 |

🔧 B안이 A안보다 반드시 좋은 문장이라는 뜻은 아닙니다. **"네 갈래가 열리는가" 하나만 놓고 고친 것**이고, 말맛·분위기·인물의 성격은 기획이 훨씬 잘 보십니다.

**세 가지 중 아무거나 하셔도 됩니다.**

1. B안 그대로 채택
2. B안을 말맛만 고쳐서 채택
3. 전부 버리고 새로 쓰기 — 이때 §1의 두 가지 조건(**사람을 가리킬 것 · 마음을 물을 것**)만 지켜 주시면 됩니다
