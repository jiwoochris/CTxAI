## 2. NPC 목소리 — Voice Design (8/8, 가장 먼저)

1. [elevenlabs.io](https://elevenlabs.io) 로그인 → **Voices → Voice Design**
2. 아래 설명을 그대로 붙여넣기:

   ```
   A calm Korean adult voice, mid-low pitch, soft and slightly worn, unhurried, close-mic intimate tone, neutral emotion, no accent, clean studio recording.
   ```

3. 마음에 드는 결과가 나오면 **「내 목소리」에 저장** — 라이브러리 목소리는 나중에 사라질 수 있어서, 저장한 목소리만 9월에도 계속 씁니다
4. 저장하면 **voice ID**가 생깁니다 (URL이나 Voice 설정에서 확인). 이 ID를 적어 두세요 — 4번 작업 전부와 9~10월 문장 층까지 이 하나만 씁니다

📐 **한 번 정하면 바꾸지 마세요.** 중간에 다른 목소리로 바꾸면 이미 만든 음성 전부를 다시 만들어야 합니다.

**감정 태그 — 실제로 먹습니다 (8/8 확인 완료).** 문장 앞에 `[calm]` `[gently]` `[quietly]` `[cheerfully]` `[sadly]` 처럼 붙이면 톤이 반영됩니다.

**넣을 텍스트:**

| 자산 | 입력 그대로 |

| Q1 | `[calm] 당신은 무엇을 기다리고 있습니까?` |

## 4. 배경 트랙 4종 — Sound Effects (8/8)

**설정:** Loop 켜기 · duration 30초 · prompt influence 0.6~0.8

**지켜야 할 것 (여덟 가지) — 네 트랙이 항상 동시에 울리기 때문:**

1. **멜로디 금지** — 패드·지속음·질감·환경음만
2. **박자 있는 소리 금지** — 드럼·아르페지오 넣으려면 네 트랙 전부 72 BPM 명시
3. **조성 통일** — 화성 들어가면 네 트랙 전부 A 마이너
4. 자리 나누기: 공포=낮게 / 로맨스=중간 따뜻하게 / 코미디=중간 가볍게 / 판타지=높고 공기처럼 (정밀 분리는 개발 EQ가 함)
5. **음량 맞추기** — 네 파일 integrated LUFS를 동일하게, 권장 **−20 LUFS**
6. **피크** — 트루 피크 −9 dBFS 목표, 못 맞추면 그대로 주고 알려만 주면 됨
7. 파일은 MP3 그대로 (변환은 개발이)
8. 이름: `bgm_H.mp3` / `bgm_R.mp3` / `bgm_C.mp3` / `bgm_F.mp3`

**프롬프트 — 그대로 붙여넣기:**

| 파일 | 프롬프트 |
|---|---|
| `bgm_H` 🖤공포 | `A minor, 72 BPM, dark ambient drone for a deserted night bus stop. Low rumbling sub bass, distant metallic groan, faint cold wind. No melody, no drums, no vocals. Seamless loop.` |
| `bgm_R` 💗로맨스 | `A minor, 72 BPM, warm ambient pad for a quiet night bus stop. Soft sustained strings in the mid range, gentle breath of air, faint distant traffic. No melody, no drums, no vocals. Seamless loop.` |
| `bgm_C` 💛코미디 | `A minor, 72 BPM, light playful ambience. Soft muted pizzicato texture, small wooden ticks, airy and bright. No melody line, no drums, no vocals. Seamless loop.` |
| `bgm_F` 💜판타지 | `A minor, 72 BPM, shimmering ethereal ambience. High airy bell-like partials, slow glassy swells, weightless. No melody, no drums, no vocals. Seamless loop.` |
