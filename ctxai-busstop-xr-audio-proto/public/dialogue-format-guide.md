## 2. 두 개의 층

### 「사건」 층 — 12줄 (8/11)

옆사람에게 **무슨 일이 있었는가.** 사건 4종 × 3줄.

🔴 **태도 중립이어야 합니다.** 이 대사는 **태도가 확정되기 전에 재생됩니다.** "붙잡으려 한다"는 내용은 있어도, 그것을 *어떤 태도로* 하는지는 아직 정해지지 않은 상태입니다.

```
✅  "그 사람이 마지막으로 여기서 버스를 탔어요."          ← 사실만
❌  "그 사람이 마지막으로 여기서 버스를 탔어요… 무서워서."  ← 태도(공포)가 섞임
```

### 「배합」 층 — 80줄 (9~10월)

**사건 4 × 태도 4 = 16벌.** 배합마다 5줄(본문 3 + 콜백 + 폴백).

🔧 **16이 기준 숫자입니다.** 다른 문서에 12나 13으로 적힌 곳이 있으면 16으로 맞춰 주세요. 순수 배합 4개(사건 = 태도)도 고유한 대사가 필요합니다.

## 3. 순번 — `1` `2` `3` 과 `cb` `cb_fb`

| 순번 | 무엇 | 길이 |
|---|---|---|
| `1` `2` `3` | 본문. 순서대로 재생됩니다 | 5초 |
| `cb` | **콜백 템플릿** — 관객이 말한 명사를 끼워 넣는 문장 | 4초 |
| `cb_fb` | **콜백 폴백** — 명사를 못 뽑았을 때 쓰는 완결 문장 | 4초 |

### 콜백이 뭔가

관객이 Q1에서 *"친구를 기다려요"* 라고 말하면, 그 **"친구"** 를 나중에 옆사람이 말합니다. 관객이 자기 단어를 되돌려 받는 순간이 이 작품의 장치입니다.

**명사 자리를 `{noun}` 으로 비워 주세요.**

```
"...아직 그 {noun} 안 왔네요."      →  ...아직 그 친구 안 왔네요.
```

**조사가 필요하면 이렇게 적어 주세요.** 받침 유무는 코드가 처리합니다.

```
"{noun|이:가} 오기로 했었나요."     →  동생이 / 친구가
"{noun|은:는} 안 올 거예요."        →  동생은 / 친구는
"{noun|을:를} 기다리시는군요."      →  동생을 / 친구를
```

📐 앞이 받침 있을 때 쓸 조사를 먼저, 없을 때를 뒤에 적으면 됩니다.

### 폴백은 왜 필요한가

관객이 *"그냥요"*, *"모르겠어요"* 라고 답하면 뽑을 명사가 없습니다. 이때 `cb` 를 쓰면 *"...아직 그 안 왔네요"* 가 되어 문장이 깨집니다.

**`cb_fb` 는 `{noun}` 없이도 완결된 문장이어야 합니다.**

```
cb      "...아직 그 {noun} 안 왔네요."
cb_fb   "...아직 안 오네요."              ← {noun} 없이 말이 됨
```

⚠️ **`cb_fb` 에는 `{noun}` 을 넣지 마세요.** 넣으면 폴백이 폴백 노릇을 못 합니다.

## 4. 최대길이(초)

**넘으면 잘리는 게 아니라 다음 대사와 겹칩니다.**

한국어 TTS가 대략 **초당 5~6자** 를 읽습니다. 5초면 **25~30자** 정도입니다.

```
"그 사람이 마지막으로 여기서 버스를 탔어요."     → 22자 · 약 4초  ✅
"그 사람이 마지막으로 여기서 버스를 탔는데 그날따라 비가 많이 왔고 저는..."  → 40자 넘음  ⚠️
```

🔧 **넘겨서 쓰셔도 됩니다.** 8/13에 만드는 배치 스크립트가 합성 후 실제 길이를 재서 넘는 행을 알려 드립니다. 그때 줄이시면 됩니다. **지금 글자 수를 세지 마세요.**

## 5. 감정태그 (선택)

ElevenLabs v3는 문장 앞에 감정 태그를 받습니다.

```
[calm] 당신은 무엇을 기다리고 있습니까?
[gently] 조금 더 말씀해 주시겠어요.
```

✅ **T6 확인 완료 (8/8) — 한국어에서 태그가 실제로 먹습니다.** 이 열에 `calm` `gently` `quietly` `cheerfully` `sadly` 처럼 적어 주시면 합성에 반영됩니다.

📐 조건은 **Stability 0.7** 로 합성할 때입니다 (개발이 배치 스크립트에 반영). 이 값보다 낮으면 문장 끝이 어색하게 늘어지는 문제가 있었습니다.

## 6. 채우는 순서 — 마감 기준

| 언제 | 무엇 | 몇 줄 |
|---|---|---|
| **8/11** | 「사건」 층 — 사건당 최소 1줄 | 4~12 |
| 8/13 | 순수 배합 4개 이름 (`H-H` `R-R` `C-C` `F-F`) | — |
| 9월 | 배합 이름 16개 (혼합 12 + 순수 4) | — |
| 9~10월 | 「배합」 층 본문 · 콜백 · 폴백 | 80 |

🔧 **8/11에는 사건당 1줄씩 4줄만 있어도 8/16 리허설이 돕니다.** 나머지 8줄은 뒤로 미루셔도 됩니다.

📐 **9~10월 80줄은 개발이 LLM으로 초안을 뽑아 드립니다** (D9). 백지에서 쓰시는 게 아니라 **고르고 고치는 작업**입니다. 8/11 사건 대사와 확정된 Q2를 보고 초안을 만들 예정입니다.
